ЭЛЕКТРОННАЯ ВИЗИТКА — ИСАЕВ АНДРЕЙ КОНСТАНТИНОВИЧ

Файлы:
index.html — главная страница GitHub Pages
card.png — изображение визитки в исходном стиле
isaev-andrey.vcf — контакт iPhone/Android с фотографией, кириллица UTF-8
portrait.jpg — фотография (отдельный файл для проекта)
telegram-qr.png — QR-код, ведущий в https://t.me/LIVEISAEV

ПУБЛИКАЦИЯ:
1. Создайте публичный репозиторий GitHub, например isaev-card.
2. Загрузите ВСЕ файлы из этой папки в корень репозитория.
3. Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save.
4. Дождитесь активации Pages: https://ВАШ-ЛОГИН.github.io/isaev-card/
5. Проверьте на iPhone скачивание VCF и наличие фотографии, кириллицы и всех полей.

ВНИМАНИЕ: сам сайт не размещён в GitHub автоматически. Ссылка появится после публикации.
