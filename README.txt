# Электронная визитка Андрея Константиновича Исаева — обновление

## Куда загружать
Существующий репозиторий: https://github.com/viacheslavisaevpro-oss/Isae-andrey
Публичная ссылка: https://viacheslavisaevpro-oss.github.io/Isae-andrey/

## Порядок действий
1. Распаковать архив на компьютере.
2. Открыть репозиторий (ссылка выше) и выбрать **Add file → Upload files**.
3. Загрузить все файлы из папки комплекта **в корень репозитория**. При совпадении имён GitHub подготовит замену файлов.
4. Внести изменения через **Commit changes** в ветку `main`.
5. Дождаться завершения GitHub Actions (`pages build and deployment`), затем открыть публичный адрес и при необходимости обновить страницу без кэша.
6. Проверить звонок, E-mail, Telegram, карту и скачивание VCF на iPhone.

**Важно:** Не создавать новый репозиторий. ZIP целиком не загружать, нужен его распакованный состав.

## Состав
- `index.html` — интерактивная страница и оформление
- `portrait.jpg` — новый официальный портрет
- `card.png` — ранее согласованная цифровая версия бумажной визитки
- `isaev-andrey.vcf` — контакт vCard 3.0, кириллица UTF-8 и встроенное фото
- `site-qr.png` — QR на публичную электронную визитку, **не Telegram**

## Оговорки
Исходная бумажная визитка представлена ранее созданной цифровой реконструкцией; это не оригинальный издательский макет Госдумы. Дополнительный портрет и графическое оформление размещены **вокруг** этого изображения. Все данные репозитория общедоступны.
